Sobre o Festival

Quero aprender mais sobre css e javascript

Geek Beats é um portal criado para estudar HTML, CSS e JavaScript a partir de um festival imaginário de música geek.

A identidade visual combina referências a cartazes de shows, grafite e concreto, aproximando a cultura geek da arte urbana.

Sobre esta demonstração

Os nomes das atrações fazem parte da proposta acadêmica. Não há anúncio de evento real, venda de ingressos ou confirmação de artistas.

Use os botões ou os links do menu para abrir uma seção por vez. As cores e o modo claro/escuro podem ser personalizados na área de avisos. Use “Ver detalhes” nos cards para abrir a proposta de cada atração. Na seção Inscrição, teste a validação demonstrativa do formulário, sem envio ou armazenamento de dados.
